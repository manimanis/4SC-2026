Négation de la condition d'arrêt
Consignes officielles impératives :
  • Interdiction absolue du break : La sortie anticipée d'une boucle par break est strictement prohibée.
  • Intégrité du compteur Pour : La variable de contrôle ne doit jamais être modifiée manuellement dans le bloc.
  • Division entière : Utiliser exclusivement l'opérateur euclidien // pour préserver le type int.
Pas négatif dans range

Pour décrémenter, la borne finale passée à range doit être F - 1.

range(10, -1, -2) # de 10 à 0
Inversion de condition

Jusqu'à indique la sortie. En Python, while évalue le maintien.

Jusqu'à (n > 2)
while not (n > 2): # ou n <= 2
Prévention de boucle infinie

Une variable intervenant dans la condition doit impérativement être modifiée à chaque itération.

temp = temp // 2
nb_div2 = nb_div2 + 1

analyse_nombre.py 
# 1. Contrôle de saisie émulant 'Répéter ... Jusqu'à' sans break
n = 0
while not (2 < n < 100):
    n = int(input("Donner un entier N (2 à 100) : "))

# 2. Somme des diviseurs avec 'for in range'
somme_div = 0
for i in range(1, n):
    if n % i == 0:
        somme_div = somme_div + i
est_parfait = (somme_div == n)
print("Le nombre est-il parfait ? :", est_parfait)

# 3. Divisions successives par 2 avec 'while'
temp = n
nb_div2 = 0
while temp % 2 == 0:
    temp = temp // 2
    nb_div2 = nb_div2 + 1
print("Nombre de divisions par 2 possibles :", nb_div2)
Points de vigilance
Borne dans range(1, n) :
Pour tester jusqu'à n - 1, la borne passée à range est n (car exclue).
Division entière // :
Utiliser temp = temp // 2 pour conserver le type int.
Interdiction de break :
Pré-initialiser n = 0 pour lancer while not (2 < n < 100): sans break.
