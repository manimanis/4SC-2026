Énoncé de la situation-problème : Analyse arithmétique

Dans le cadre de l'étude des propriétés fondamentales des nombres entiers (exploitées notamment en cryptographie), on souhaite concevoir un programme automatisé d'analyse d'un entier positif N.

Ce programme doit réaliser les trois opérations suivantes :

  1. Contrôle de saisie sécurisé : Saisir un entier N strictement compris entre 2 et 100 (c'est-à-dire 2 < N < 100).
  2. Recherche des diviseurs stricts & test du nombre parfait : Calculer la somme de tous les diviseurs stricts de N (tous les entiers i de 1 à N div 2 qui divisent N). Un nombre est dit parfait s'il est égal à la somme de ses diviseurs stricts (exemples : 6 car 1 + 2 + 3 = 6 et 28 car 1 + 2 + 4 + 7 + 14 = 28).
  3. Divisions successives par 2 (Réduction binaire) : Compter combien de divisions entières successives par 2 le nombre N peut-il subir.

Structure Algorithmique (Norme) Python (Conventions 2024-2025)

Jusqu'à Condition

    Traitement
Négation de la condition d'arrêt
Consignes officielles :
  • Interdiction absolue du break : La sortie anticipée d'une boucle par break est strictement prohibée.
  • Intégrité du compteur Pour : La variable de contrôle ne doit jamais être modifiée manuellement dans le bloc.
  • Division entière : Utiliser exclusivement l'opérateur euclidien // pour préserver le type int.
Pas négatif dans range

Pour décrémenter, la borne finale passée à range doit être F - 1. 

# Décompte décroissant de 10 à 0
for i in range(10, -1, -2):
    print(i)
Inversion de condition

Jusqu'à indique l'arrêt. En Python, while évalue le maintien. 

# Répéter ... Jusqu'à (n > 2)
while not (n > 2):  # ou while n <= 2:
    n = int(input("N = "))
Prévention de boucle infinie

La variable de condition doit impérativement évoluer vers l'arrêt à chaque tour. 

while temp % 2 == 0:
    temp = temp // 2  # Vers l'arrêt
    nb_div2 = nb_div2 + 1
