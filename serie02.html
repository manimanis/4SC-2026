Exercice 3 : Intersection de deux cercles

🟡 Moyen Forme généralisée

Soient deux cercles du plan C1 et C2 de rayons respectifs r1 et r2 , les centres des deux cercles étant à une distance d donnée.

Ces deux cercles :

  • sont confondus , si d = 0 et r1 = r2
  • sont disjoints intérieurement , si d = 0 et r1 ≠ r2
  • sont disjoints intérieurement , si 0 < d < |r1 - r2|
  • sont tangents intérieurement , si d = |r1 - r2|
  • sont sécants , si |r1 - r2| < d < r1 + r2
  • sont tangents extérieurement , si d = r1 + r2
  • sont disjoints extérieurement , si d > r1 + r2

On demande d'écrire un programme qui saisit les données mentionnées puis affiche la position relative des deux cercles.

💡 Structure recommandée : Forme généralisée
Algorithme 
Si condition1 Alors
  // Traitement 1
Sinon Si condition2 Alors
  // Traitement 2
...
Fin Si
Python 
if condition1:
    # Traitement 1
elif condition2:
    # Traitement 2
...
Indice : Comparer la distance d aux expressions |r1 - r2| et r1 + r2 dans l'ordre pour identifier le cas géométrique.

Rayon de C2 ? 3
Distance entre les centres ? 9

Exercice 4 : Jeu de trois dés

  • Au moins un 6, on gagne 50 pts
  • Dans les autres cas, on gagne la somme des trois dés

On demande d'écrire un programme qui :

  • Simule le lancement de trois dés (valeurs aléatoires entre 1 et 6)

  // Gain minimal (50 pts)
Sinon
  // Gain standard (Somme)
Fin Si
Python

    # Gain 300 pts
elif condition2:
    # Gain 200 pts
elif condition3:
    # Gain 50 pts
else:
    # Gain somme
