« À partir d'un code (ex: "info-2026"), vérifier que le suffixe est numérique, passer le préfixe en majuscules ("INFO") et incrémenter l'année pour produire "INFO-2027". »

  • 1
    Séparateur : Position de "-" via Pos / .find().

"info-2026" "INFO-2027"

15 min
Primitive Algorithme Python
Indiçage (1er car.) Ch[0]  (0 ≤ i < Long(Ch)) ch[0]  (Base 0)
Longueur Long(ch) len(ch)
Position Pos(ch1, ch2)  (-1 si absent) ch2.find(ch1)  (-1 si absent)
Sous-chaîne Sous_chaine(ch, d, f)  (f exclue) ch[d:f]  (f exclu)

Vers nombre Valeur(ch) int(ch) / float(ch)
Vers chaîne Convch(x) str(x)
ASCII / Caractère Ord(c)  |  Chr(d) ord(c)  |  chr(d)
À retenir :
  • Base 0 : Premier caractère en Ch[0].
  • Fin exclue : Dans Sous_chaine(ch, d, f) et ch[d:f], f est exclue (longueur = f - d).
  • Absence : Pos et .find() renvoient -1.

Algorithme & Programme MajCode

25 min
ALGORITHME MajCode Programme Principal 
ALGORITHME MajCode
DEBUT
    // Saisie du code
    Écrire("Donner le code (ex: info-2026) : ")
    Lire(code)
    
    // Position du tiret et découpage
    p ← Pos("-", code)
    prefixe ← Sous_chaine(code, 0, p)
    suffixe ← Sous_chaine(code, p + 1, Long(code))
    
    // Vérification que le suffixe est numérique
    valide ← Estnum(suffixe)
    
    Si valide Alors
        // Préfixe en majuscules et incrémentation de l'année
        annee ← Valeur(suffixe)
        nouvelle_annee ← annee + 1
        nouveau_code ← Majus(prefixe) + "-" + Convch(nouvelle_annee)
        Écrire("Nouveau code : ", nouveau_code)
    Sinon
        Écrire("Erreur : le suffixe n'est pas numérique !")
    Fin Si
FIN

Objet Type Rôle

traitement_code.py 
# Saisie du code
code = input("Donner le code (ex: info-2026) : ")

# Position du tiret et découpage
p = code.find('-')
prefixe = code[0:p]
suffixe = code[p + 1:]

# Vérification que le suffixe est numérique
valide = suffixe.isdecimal()

if valide:
    # Préfixe en majuscules et incrémentation de l'année
    annee = int(suffixe)
    nouvelle_annee = annee + 1
    nouveau_code = prefixe.upper() + "-" + str(nouvelle_annee)
    print("Nouveau code :", nouveau_code)
else:
    print("Erreur : le suffixe n'est pas numérique !")
