Synthèse des correspondances : Scalaires & Fonctions arithmétiques

15 minutes
Notion / Opération Algorithmique (Norme Officielle) Python (Conventions 2024-2025)
Types scalaires Entier, Réel, Booléen int, float, bool (True, False)
Division réelle /  (ex: 14 / 3 → 4.666...) /  (résultat toujours réel float)
Division entière : Quotient Div  (ex: 14 Div 3 → 4) //  (ex: 14 // 3 → 4)
Division entière : Reste Mod  (ex: 14 Mod 3 → 2) %  (ex: 14 % 3 → 2)
Racine carrée Racine(x) sqrt(x)  (après from math import sqrt)
Arrondi entier Arrondi(x)  (arrondi au plus proche) round(x)
Troncature entière Ent(x)  (partie entière tronquée) int(x)
Valeur absolue Abs(x) abs(x)
Génération aléatoire Aléa(vi, vf)  (entier dans [vi, vf]) randint(vi, vf)  (après from random import randint)
Règles normatives essentielles pour les types numériques :
  • L'opérateur Div et la fonction Ent(x) retournent un type Entier. La division / produit toujours un Réel.
  • En Python, les fonctions sqrt et randint nécessitent un import explicite (from math import sqrt et from random import randint).

Étape 1

Accroche & Situation-problème : Code d'inscription textuel

10 minutes
Énoncé au tableau
« Une application reçoit un code d'inscription sous la forme d'une chaîne, par exemple "info-2026". On souhaite vérifier si le suffixe après le tiret "-" est bien composé uniquement de chiffres, mettre le préfixe en majuscules ("INFO"), convertir l'année en entier pour calculer l'année suivante, puis afficher le code mis à jour sous la forme "INFO-2027". »
Cette situation permet de mobiliser les traitements textuels fondamentaux : recherche de séparateur, extraction de tranches, validation numérique, conversion de types et assemblage par concaténation.
Décomposition du traitement textuel :
  • 1
    Localisation du séparateur : Recherche de la position du tiret "-" avec Pos / .find().
  • 2
    Découpage préfixe / suffixe : Extraction avec Sous_chaine / slicing [d:f] (borne f exclue).
  • 3
    Validation & Conversion : Test avec Estnum / isdecimal(), conversion avec Valeur / int() et incrémentation (+ 1).
  • 4
    Recomposition du nouveau code : Majuscules avec Majus / .upper(), conversion avec Convch / str() et concaténation +.
Transformation Visuelle
"info-2026" "INFO-2027"
• Préfixe : "info" → "INFO"
• Séparateur : "-" (indice 4)
• Suffixe : "2026" → 2026 + 1 = 2027

Étape 2

Synthèse des correspondances : Primitives textuelles & Indiçage base 0

15 minutes
Primitive textuelle Algorithmique (Norme Officielle) Python (Conventions 2024-2025)
Indiçage (1er élément) Ch[0]  (0 ≤ i < Long(Ch)) ch[0]  (Indexation base 0)
Longueur d'une chaîne Long(ch) len(ch)
Recherche de position Pos(ch1, ch2)  (retourne -1 si absent) ch2.find(ch1)  (retourne -1 si absent)
Extraction de sous-chaîne Sous_chaine(ch, d, f)  (borne f exclue) ch[d:f]  (slicing, indice f exclu)
Suppression de tranche Effacer(ch, d, f)  (borne f exclue) ch[:d] + ch[f:]
Passage en majuscules Majus(ch) ch.upper()
Test numérique Estnum(ch) ch.isdecimal()
Conversion vers nombre Valeur(ch) int(ch) ou float(ch)
Conversion vers chaîne Convch(x) str(x)
Code ASCII / Caractère Ord(c)  |  Chr(d) ord(c)  |  chr(d)
Règles fondamentales pour les chaînes de caractères :
  • Indiçage obligatoire en base 0 : Le premier caractère d'une chaîne Ch est toujours Ch[0].
  • Borne de fin toujours exclue : Dans Sous_chaine(ch, d, f) et dans le slicing Python ch[d:f], la position finale f est exclue. L'extraction comprend exactement f - d caractères.
  • Retour de recherche absente : Si la chaîne n'existe pas, Pos et .find() renvoient impérativement -1.

traitement_code.py 
# Saisie du code d'inscription
code = input("Donner le code (ex: info-2026) : ")

# Recherche de la position du tiret séparateur
p = code.find('-')

if p != -1:
    prefixe = code[0:p]
    suffixe = code[p + 1:]
    
    # Mise en majuscules du préfixe
    prefixe_maj = prefixe.upper()
    
    # Test numérique et incrémentation de l'année
    if suffixe.isdecimal():
        annee = int(suffixe)
        nouvelle_annee = annee + 1
        nouveau_code = prefixe_maj + "-" + str(nouvelle_annee)
    else:
        nouveau_code = prefixe_maj + "-" + suffixe
else:
    nouveau_code = code.upper()

print("Nouveau code généré :", nouveau_code)
