Situation mobilisatrice

Système d'échantillonnage d'un laboratoire de recherche

Au sein d'un laboratoire d'analyses biomédicales, chaque échantillon biologique ou chimique prélevé reçoit un identifiant sécurisé apposé sur son flacon. Avant tout dosage et traitement statistique des concentrations, l'automate doit impérativement contrôler la syntaxe de l'identifiant et lui associer une clé numérique de contrôle.

Format officiel du code flacon :
@CH-94B
  • Commence obligatoirement par le préfixe @
  • Comporte un nom de réactif (ex : CH pour Chlorure)
  • Contient un tiret de séparation -
  • Suivi d'un nombre à deux chiffres (ex : 94)
  • Se termine par une lettre majuscule de contrôle (ex : B)
Enjeu informatique :

Éviter la duplication de code et fiabiliser le système grâce à la modularité :

Module 1 : Valide_Code(ch) (Validation textuelle) Module 2 : Cle_Controle(ch_num) (Génération numérique)
Durée estimée : 60 min (4 phases interactives)

Phase 1 : Mise en situation (10 min)

Analyse du problème

Examinons les contraintes formelles appliquées à une chaîne ch représentant l'identifiant du flacon :

Composant Spécification Exemple valide Contre-exemples invalides
Symbole de début Premier caractère égal à "@" @CH-94B CH-94B (manque l'@)
Séparateur Présence du caractère tiret "-" après le préfixe @CH-94B @CH_94B, @CH94B
Partie numérique Exactement 2 caractères décimaux [0-9] après le tiret @CH-94B @CH-9B (1 seul chiffre), @CH-945B (3 chiffres)
Lettre de contrôle Dernier caractère alphabétique majuscule [A-Z] @CH-94B @CH-94b (minuscule), @CH-948 (chiffre)

Implémentation Python Valide_Code 
def Valide_Code(ch):
    ch = ch.upper()
    valide = False
    p = ch.find("-")
    L = len(ch)
    
    # Vérification structurelle : préfixe, tiret et positionnement
    if L >= 6 and ch[0] == "@" and p > 1 and p + 3 < L:
        ch_num = ch[p + 1 : p + 3]
        lettre = ch[p + 3]
        
        # Validation des deux chiffres et du caractère de contrôle [A-Z]
        if len(ch_num) == 2 and ch_num.isdecimal() and (ord("A") <= ord(lettre) <= ord("Z")):
            valide = True
            
    return valide

Phase 3 : Activité modulaire 2 – Calcul de clé numérique (15 min)

Module : Cle_Controle

Une fois le code validé, l'automate de laboratoire génère une clé de contrôle numérique à partir de la valeur entière des deux chiffres ch_num.

Primitives numériques officielles (Conventions 2024-2025) :

Fonction en Algorithmique Rôle & Comportement Équivalent en Python Bibliothèque requise
Valeur (ch) Convertit une chaîne numérique en entier ou réel int(ch) ou float(ch) Standard
Abs (x) Retourne la valeur absolue |x| abs(x) Standard
RacineCarré (x) Retourne la racine carrée √x pour x ≥ 0 sqrt(x) from math import sqrt
Arrondi (x) / Ent (x) Entier le plus proche / Partie entière round(x) / int(x) Standard
Aléa (vi, vf) Entier aléatoire dans l'intervalle [vi, vf] randint(vi, vf) from random import randint
Convch (x) Convertit un nombre x en chaîne de caractères str(x) Standard

Règle de calcul de la clé :

  1. Conversion du nombre : x ← Valeur(ch_num) (ex : 94).
  2. Calcul d'écart avec la médiane 50 : ecart ← Abs(x - 50) (ex : |94 - 50| = 44).
  3. Calcul de dérive : derive ← RacineCarré(ecart) (ex : √44 ≈ 6.633).
  4. Approximation mise à l'échelle : base ← Arrondi(derive × 10) (ex : 66).
  5. Ajout d'un jeton aléatoire de sécurité : secu ← Aléa(10, 99) (ex : 73).
  6. Combinaison finale : res ← base × 100 + secu (ex : 6673).
  7. Retour de la clé sous forme de chaîne textuelle grâce à Convch(res).

Implémentation Python Cle_Controle 
from math import sqrt
from random import randint

def Cle_Controle(ch_num):
    x = int(ch_num)
    ecart = abs(x - 50)
    derive = sqrt(ecart)
    base = round(derive * 10)
    secu = randint(10, 99)
    res = base * 100 + secu
    
    return str(res)

from math import sqrt
from random import randint

# Définition de la fonction Valide_Code
def Valide_Code(ch):
    ch = ch.upper()
    valide = False
    p = ch.find("-")
    L = len(ch)
    
    if L >= 6 and ch[0] == "@" and p > 1 and p + 3 < L:
        ch_num = ch[p + 1 : p + 3]
        lettre = ch[p + 3]
        if len(ch_num) == 2 and ch_num.isdecimal() and (ord("A") <= ord(lettre) <= ord("Z")):
            valide = True
    return valide

# Définition de la fonction Cle_Controle
def Cle_Controle(ch_num):
    x = int(ch_num)
    ecart = abs(x - 50)
    derive = sqrt(ecart)
    base = round(derive * 10)
    secu = randint(10, 99)
    res = base * 100 + secu
    return str(res)

# Programme principal
code_flacon = input("Entrer le code de l'échantillon (@CH-94B) : ")

if Valide_Code(code_flacon):
    p = code_flacon.find("-")
    num_extrait = code_flacon[p + 1 : p + 3]
