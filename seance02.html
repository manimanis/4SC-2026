Étape 1

Situation & Simulateur (Tarif d'accès)

15 minutes
Énoncé de la situation-problème
Complexe Sportif

Un complexe sportif souhaite automatiser la facturation d'un accès journalier dont le tarif de base est fixé à 20 DT.

Le client indique son âge (entier positif) et choisit une formule via un code caractère (majuscule ou minuscule) :

  • Formule Piscine ('P' ou 'p') : supplément de +5 DT.
  • Formule Musculation ('M' ou 'm') : supplément de +10 DT.
  • Formule Accès Total ('T' ou 't') : supplément de +15 DT.
  • Tout autre code : la formule est considérée comme invalide.

Si la formule est valide, le prix brut est calculé par : Prix brut = 20 DT + Supplément. Une remise selon l'âge est ensuite appliquée pour obtenir le montant net à payer :

  • Moins de 12 ans (< 12) : Gratuit (remise de 100%, net = 0 DT).
  • De 12 à 17 ans inclus : Réduction de 50% (prix_net = prix_brut * 0.5).
  • 60 ans et plus (≥ 60) : Réduction de 20% (prix_net = prix_brut * 0.8).
  • De 18 à 59 ans : Plein tarif (sans remise, prix_net = prix_brut).
Accès Journalier : Piscine | Muscu | Total
Travail demandé : Écrire l'algorithme (puis le programme Python correspondant) permettant de saisir l'âge et la formule, puis de calculer et d'afficher le montant net à payer (en DT), ou le message d'erreur "Formule invalide !" si le code est non reconnu.

Exemple d'intervalle dans un Selon (Tranches de valeurs) Intervalle : ..

En algorithmique, un intervalle s'écrit avec deux points borne_min .. borne_max (bornes incluses). En Python (match-case), on utilise une condition de garde (case x if ...:).

Algorithmique : 
Selon note
    0 .. 9 : Écrire("Insuffisant")
    10 .. 13 : Écrire("Moyen")
    14 .. 16 : Écrire("Bien")
    17 .. 20 : Écrire("Très Bien")
    Sinon
        Écrire("Note invalide")
Fin Selon
Python (3.10+) : 
match note:
    case n if 0 <= n <= 9:
        print("Insuffisant")
    case n if 10 <= n <= 13:
        print("Moyen")
    case n if 14 <= n <= 16:
        print("Bien")
    case n if 17 <= n <= 20:
        print("Très Bien")
    case _:
        print("Note invalide")
À retenir :
  • Selon : Le sélecteur doit être un Entier ou un Caractère.
  • Clause par défaut : case _ : en Python correspond au Sinon du Selon.
  • Indentation : 4 espaces obligatoires en Python (remplace FinSi / Fin Selon).
Égalité : = vs ==

En algo : = (affectation : ←). En Python : == (affectation : =). 

valide ← (age = 18)
valide = (age == 18)
Choix multiple (|)

En Python, séparer les options d'un case par | (et non une virgule). 

case "P" | "p":  # Correct
# Erreur : case "P", "p":
Encadrement

En algo : avec Et. En Python : comparaison chaînée directe. 

(age ≥ 12) Et (age ≤ 17)
12 <= age <= 17
