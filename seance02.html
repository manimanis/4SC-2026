Accroche et situation-problème

10 minutes
Énoncé au tableau
« Un centre sportif calcule le tarif d'un accès journalier (tarif de base : 20 DT). Le client fournit son âge et un code de formule sous forme d'un caractère : 'P' (Piscine : +5 DT), 'M' (Musculation : +10 DT) ou 'T' (Total : +15 DT). Tout autre code entraîne un message d'erreur. De plus, une remise est accordée selon l'âge : gratuit pour les moins de 12 ans, 50% de réduction pour les juniors (12 à 17 ans inclus) et 20% pour les seniors (60 ans et plus). Calculer et afficher le prix net à payer. »
Cette situation permet de mobiliser les deux types d'arbres décisionnels : le choix multiple sur valeurs discrètes (sélecteur caractère) et la décision en cascade sur intervalles numériques continus (tranches d'âge).
1. Formules & Suppléments (Choix multiple) :
  • 'P' ou 'p' Piscine
    +5 DT
  • 'M' ou 'm' Musculation
    +10 DT
  • 'T' ou 't' Accès Total
    +15 DT
  • Autre code Code non reconnu
    Erreur
Tarif brut = Tarif de base (20 DT) + Supplément.
2. Remises par Tranche d'Âge (Conditions continues) :
  • < 12 ans Enfants
    Gratuit (100% remise)
  • 12 à 17 ans Juniors
    -50% (prix × 0.5)
  • ≥ 60 ans Seniors
    -20% (prix × 0.8)
  • 18 à 59 ans Adultes

Rappels didactiques et normatifs majeurs :
  • Type scalaire obligatoire pour le Selon : Le sélecteur de la structure Selon doit être impérativement de type Entier ou Caractère.
  • Clause par défaut en Python : Dans le bloc match-case, le tiret de soulignement case _ : représente la clause par défaut équivalente au Sinon du Selon.
  • Indentation syntaxique obligatoire : En Python, l'indentation (4 espaces) remplace impérativement les délimiteurs textuels (FinSi, Fin Selon).
Test d'égalité : = vs ==

En algorithmique, l'égalité se note = (l'affectation étant ←). En Python, le test d'égalité s'écrit obligatoirement ==.

valide ← (age = 18)
valide = (age == 18)
Alternative match-case (|)

Pour grouper plusieurs valeurs dans un case en Python, on emploie le symbole pipe | et jamais la virgule.

# Valide en Python 3 :
case "P" | "p":
# INTERDIT : case "P", "p":
Encadrement numérique

En algorithmique, l'encadrement nécessite Et. En Python, la double comparaison chaînée est directement acceptée.

(age ≥ 12) Et (age ≤ 17)
12 <= age <= 17

Étape 4

Traduction, Exécution sur machine & Laboratoire

20 minutes

Saisie individuelle du script Python par les élèves en appliquant rigoureusement les conventions officielles (Python 3.10+) :

tarif_acces.py 
# Entrées
age = int(input("Donner l'âge du client : "))
formule = input("Donner le code de formule (P, M ou T) : ")

# Structure à choix multiples (match / case)
supplement = 0
valide = True
match formule:
    case "P" | "p":
        supplement = 5
    case "M" | "m":
        supplement = 10
    case "T" | "t":
        supplement = 15
    case _:
        valide = False

# Traitement conditionnel imbriqué et généralisé
if not valide:
    print("Formule invalide !")
else:
    prix_brut = 20 + supplement
    if age < 12:
        prix_net = 0.0
    elif 12 <= age <= 17:
        prix_net = prix_brut * 0.5
    elif age >= 60:
        prix_net = prix_brut * 0.8
    else:
        prix_net = float(prix_brut)
    print("Montant net à payer :", prix_net, "DT")
Points d'attention & Vigilance enseignant
Respect de l'opérateur pipe | dans case :
Vérifier l'utilisation impérative de la barre verticale case "P" | "p": pour l'alternative. La virgule , est une faute de syntaxe dans ce contexte.
Différenciation stricte de l'affectation et de l'égalité :
Veiller à ce que l'opérateur de comparaison == ne soit jamais confondu avec l'affectation = dans les expressions booléennes.
Rigueur absolue des niveaux d'indentation :
Contrôler l'alignement des sous-blocs : le bloc intérieur au match, puis l'imbrication du if-elif-else à l'intérieur du else principal.
