Exercice 1 : Identificateurs, Aléa & Tableaux

🟢 Facile Bac 2016 adapté
💡 Rappel de cours : Identificateurs & Fonction Aléa
  • Un identificateur commence par une lettre ou un souligné _ (pas de chiffre initial, pas d'espaces ni de tirets).
  • En Algorithme, Aléa(a, b) génère un entier aléatoire dans l'intervalle fermé [a, b].
  • En Python, un tableau est représenté par un array NumPy dont les indices commencent obligatoirement par 0.

Cocher les bonnes réponses :

Question 1

L’identificateur d’une variable :

  • Ne doit pas commencer par un chiffre
  • Peut contenir un espace
  • Peut contenir le caractère souligné « _ »
Question 2

L’instruction qui permet d’affecter à une variable X, une valeur aléatoire de l’intervalle [2, 10] est :

  • X ← 2 + Aléa(0, 10)
  • X ← 2 + Aléa(0, 8)
  • X ← Aléa(2, 10)
  • X ← Aléa(2, 11)
Question 3

Une structure de données tableau peut :

  • Contenir des éléments de types différents
  • Etre déclarée avec une taille maximale variable
  • Avoir des indices négatifs
  • Avoir des indices commençant par 0

Exercice 6 : Évaluation & Typage d'Expressions

🟡 Moyen Bac 2007
💡 Rappel de cours : Opérateurs & Fonctions prédéfinies
  • ord(c) retourne le code ASCII du caractère c (ex: ord("A") = 65, ord("D") = 68).
  • chr(n) retourne le caractère correspondant au code ASCII n (ex: chr(52) = "4").
  • ABS(x) retourne la valeur absolue du nombre x.
  • div donne le quotient entier et MOD donne le reste de la division entière.
  • Les caractères sont comparés selon leurs codes ASCII (ex: "D" < "A" s'évalue à Faux car 68 < 65).

Exercice 9 : Traduction de Formules Mathématiques

🟡 Moyen
💡 Rappel de cours : Traduction de formules mathématiques
  • Opérateur de multiplication : La multiplication implicite (ex: $2x$) doit obligatoirement s'écrire avec l'opérateur * (ex: 2 * x).
  • Racine carrée : S'écrit racine(X) en Algorithme et sqrt(X) en Python (module math).
  • Valeur absolue : S'écrit abs(X) ou ABS(X) en Algorithme et en Python.
  • Priorités & Parenthèses : Entourer systématiquement le numérateur et le dénominateur composés de parenthèses (...) pour garantir le bon ordre des opérations.

Donner en algorithmique et en Python l’équivalent de chacune des expressions arithmétiques suivantes :

Formule A
$$A = \frac{(x + 1)^2}{\sqrt{x}}$$
Formule B
$$B = \frac{2x^2 + 4x - 1}{\sqrt{|x + 5|}}$$
Formule C
$$C = \sqrt{\frac{|10x + 2|}{3}}$$
Formule D
$$D = \frac{x^3}{(x^2 + 2)} - 1$$
💡 Indices détaillés formule par formule
Formule A
  • Numérateur : (x + 1)*(x + 1)
  • Dénominateur : racine(x) (Algo) / sqrt(x) (Python)
Formule B
  • Numérateur : (2 * x * x + 4 * x - 1)
  • Dénominateur : racine(abs(x + 5))
Formule C
  • Numérateur intérieur : abs(10 * x + 2)
  • Fraction globale sous la racine : abs(10 * x + 2) / 3
Formule D
  • Numérateur : x * x * x | Dénominateur : (x * x + 2)
  • Soustraction extérieure : - 1
📌 Exemple guidé : Pour traduire $E = \frac{x + 3}{\sqrt{x^2 + 1}}$ :
  • Algorithme : E ← (x + 3) / racine(x**2 + 1)
  • Python : E = (x + 3) / sqrt(x**2 + 1)
