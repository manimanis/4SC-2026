Séance 01

Structures de données

Maîtrise des types numériques (Entier, Réel, Booléen) et textuels (Caractère, Chaîne), division euclidienne (Div/Mod) & fonctions prédéfinies.

Savoirs associés & Compétences :
  • Types simples : Entier, Réel, Booléen, Caractère, Chaîne
  • Opérateurs de division : div, mod et /.
  • Fonctions arithmétiques : Racine, Arrondi, Ent, Abs, Aléa
  • Fonctions prédéfinies textuelles : Long, Pos, Sous_chaine, Effacer, Majus
  • Conversions & tests : Estnum, Valeur, Convch, Ord, Chr
Inclus : Cours didactique + Repère 2D + Analyseur + Série N°1 (11 exercices & Bac).

Structures conditionnelles & Choix multiples

Formes simple, alternative, généralisée, structure à choix multiples (Selon / match-case), opérateurs relationnels et logiques.

  • Structures : Si...FinSi, Si...Sinon...
  • Choix multiple : Selon & match-case

Directives & Recommandations Officielles

À retenir

En Algorithmique :

  • L'indice du 1er élément d'une chaîne et d'un tableau est 0.
  • Le passage par adresse s'écrit avec le préfixe @ devant le nom du paramètre formel (ex: @T : TabCodes).
  • Une fonction retourne un résultat unique de type simple via Retourner Résultat.
  • Les nouveaux types de tableaux doivent impérativement figurer dans le TDNT.

En Programmation Python :

  • Les tableaux sont obligatoirement implémentés avec from numpy import array.
  • L'affichage d'un tableau doit se faire élément par élément (l'instruction print(T) est proscrite).
  • Interdiction formelle d'utiliser l'instruction break pour forcer l'arrêt des boucles for ou while.
  • Interdiction d'utiliser des fonctions ne figurant pas dans la liste officielle des conventions.
