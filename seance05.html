Étape 2

Modes de passage & Portée des identificateurs

15 min
Critère Fonction Procédure
Rôle principal Calcule et retourne une valeur unique Exécute un traitement (action, affichage, modification)
En-tête algorithmique Fonction Nom(...) : Type_simple Procédure Nom(pf1: T1, @pf2: T2)
Syntaxe d'appel Dans une expression : v ← Nom(...) Instruction autonome : Nom(...)
Modification d'arguments Non (calcul pur) Possible via le passage par adresse (@)
Passage par valeur (par défaut)

Le paramètre effectif transmet une copie de sa valeur. La variable de l'appelant reste totalement inchangée.

Procédure Afficher(val: Entier)
Passage par adresse (@)

Le paramètre formel pointe directement sur la case mémoire de la variable effective. Toute modification est répercutée.

Procédure Permuter(@a: Entier, @b: Entier)
Variable Locale (T.D.O.L.)

Déclarée au sein du sous-programme. Accessible exclusivement dans son bloc d'exécution. Détruite dès la sortie du module.

Variable Globale (T.D.O.G.) & mot-clé global

Déclarée dans le programme principal. En Python, si une procédure doit modifier une variable simple globale sans retour, elle la déclare via global nom_var.

// 1. Procédure de saisie contrôlée par variable (@n)
Procédure Saisie (@n: Entier, min: Entier, max: Entier)
DEBUT
    Répéter
        Écrire("Donner un entier entre ", min, " et ", max, " : ")
        Lire(n)
    Jusqu'à (n ≥ min) Et (n ≤ max)
FIN

// 2. Procédure de permutation par variable (@a, @b)
Procédure Permuter (@a: Entier, @b: Entier)
DEBUT
    aux ← a
    a ← b
    b ← aux
FIN

// 3. Procédure d'affichage avec passage par valeur
Procédure AfficherCouple (msg: Chaîne, v1: Entier, v2: Entier)
DEBUT
    Écrire(msg, " : X = ", v1, " | Y = ", v2)
FIN

// 4. Algorithme Principal

# 1. Procédure de saisie (contrôle sans break)
def saisie_intervalle(borne_min, borne_max):
    val = 0
    while not (borne_min <= val <= borne_max):
        val = int(input(f"Donner un entier entre {borne_min} et {borne_max} : "))
    return val

# 2. Procédure de permutation via mot-clé global (Convention 2024)
def permuter():
    global x, y
    aux = x
    x = y
    y = aux

# 3. Procédure d'affichage (passage par valeur)
def afficher_couple(msg, a, b):
    print(msg, "-> X =", a, "| Y =", b)

# --- Programme Principal ---
x = saisie_intervalle(1, 100)
y = saisie_intervalle(1, 100)

afficher_couple("Avant permutation", x, y)
permuter()
afficher_couple("Après permutation", x, y)
Conformité Officielle
  • Mot-clé global : Conformément à la convention d'inspection 2024 (section 7.d), la modification de scalaires globaux en procédure se déclare avec global.
  • Paramètre variable (@) : En algorithmique, le symbole @ est obligatoire devant les paramètres formels modifiés.
  • Règle d'appel : L'appel d'une procédure s'effectue comme une instruction autonome, sans affectation.
